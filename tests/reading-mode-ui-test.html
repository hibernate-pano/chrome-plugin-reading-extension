阅读模式UI重构演示

这是一个用于测试阅读模式UI重构的演示页面。它包含了各种类型的内容，包括文本、代码、图片、表格等，以便全面测试阅读模式的功能。

功能特性

重构后的阅读模式UI包含以下主要特性：

  • 现代化设计：使用Shadcn/UI组件和Tailwind CSS
  • 标签页设置：基础、高级、主题三个设置分类
  • 主题预设：经典、现代、深色、护眼、高对比等预设主题
  • 拖拽支持：可以拖拽移动控制面板
  • 快捷键支持：Ctrl+R切换、Ctrl+/-调整字体等
  • 设置管理：导入、导出、重置设置

代码示例

以下是一些代码示例：


// 阅读模式设置示例
const readingSettings = {
  theme: 'light',
  fontSize: 16,
  fontFamily: 'serif',
  backgroundColor: 'cream',
  lineHeight: 1.6,
  paragraphSpacing: 16,
  textAlign: 'left',
  showImages: true,
  codeTheme: 'github',
  codeFontSize: 14
};

// 应用设置
function applyReadingSettings(settings) {
  Object.entries(settings).forEach(([key, value]) => {
    document.documentElement.style.setProperty(`--${key}`, value);
  });
}
