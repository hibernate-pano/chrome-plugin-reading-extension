# Product Overview

AI Reading Extension is a Chrome browser extension focused on providing a clean, immersive reading experience for web pages.

## Core Value Proposition
- **Minimalist Design**: Simple popup interface with one-click reading mode toggle
- **Local-First**: All data stored locally using Chrome Storage API, no cloud dependencies
- **Privacy-Focused**: No user tracking or data collection

## Key Features
- Smart content extraction using Mozilla Readability
- Multiple themes (light, dark, sepia)
- Customizable typography (font size, line height, font family, page width)
- Code syntax highlighting for technical articles
- Web Workers for background content processing
- Floating settings panel for quick adjustments

## Target Users
- Readers who want distraction-free web content consumption
- Technical users reading documentation and code-heavy articles
- Privacy-conscious users who prefer local-only solutions
