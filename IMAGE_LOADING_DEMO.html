📸 图片加载优化演示

对比传统加载 vs 优化后的渐进式加载

旧方式 传统加载

感知加载时间 -
用户体验 ❌ 等待时间长
视觉反馈 ❌ 无占位符

新方式 渐进式加载

感知加载时间 -
用户体验 ✅ 立即反馈
视觉反馈 ✅ 模糊占位符

🚀 核心优化特性

🎨 渐进式加载

先显示模糊占位符，再平滑过渡到清晰图片，消除加载白屏

⚡ 异步解码

使用 decode() API 在后台解码图片，避免阻塞主线程

🎯 并发控制

智能限制同时加载的图片数量，优先加载可见区域

🌙 空闲预加载

使用 requestIdleCallback 在浏览器空闲时预加载图片

📱 设备自适应

根据设备内存和网络状况自动调整加载策略

♿ 可访问性

支持 prefers-reduced-motion，为有需求的用户禁用动画
