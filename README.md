# AI Reading Extension

一个基于 AI 的 Chrome 阅读扩展，旨在提供更好的网页阅读体验。

## 项目简介

AI Reading Extension 是一个 Chrome 浏览器扩展，它能够优化网页的阅读体验，提供多种阅读辅助功能。主要功能包括：

- 智能排版优化
- 段落间距调整
- 中英文间自动添加空格
- 自定义阅读设置
- 代码高亮显示

## 技术栈

- **前端框架**: React 18
- **开发语言**: TypeScript
- **构建工具**: Vite
- **状态管理**: Zustand
- **样式方案**: Tailwind CSS
- **UI 组件**: Headless UI
- **代码高亮**: Prism.js
- **其他工具**:
  - Pangu.js (中英文间距处理)
  - Mozilla Readability (阅读模式实现)

## 项目结构

```
src/
├── background/       # Chrome 扩展后台脚本
├── content/         # 注入页面的内容脚本
│   ├── content.tsx
│   └── content.css
├── popup/          # 扩展弹出窗口
│   ├── components/
│   └── Popup.tsx
├── options/        # 扩展配置页面
├── storage/        # 数据存储相关
└── store.ts        # 全局状态管理

public/            # 静态资源
├── manifest.json   # Chrome 扩展配置文件
└── icons/         # 扩展图标

docs/             # 项目文档
```

## 模块功能说明

### 1. 内容脚本 (Content Script)

- 负责页面内容的处理和优化
- 实现阅读模式转换
- 处理段落间距和排版
- 实现代码块高亮

### 2. 弹出窗口 (Popup)

- 提供快捷功能访问
- 显示当前页面状态
- 提供设置面板入口

### 3. 设置页面 (Options)

- 提供详细的扩展配置选项
- 自定义样式设置
- 功能开关控制

### 4. 存储模块 (Storage)

- 管理用户设置和偏好
- 处理数据持久化
- 提供数据同步功能

### 5. 状态管理 (Store)

- 使用 Zustand 管理全局状态
- 处理组件间的数据共享
- 管理用户交互状态

## 开发指南

### 环境要求

- Node.js >= 16
- pnpm 包管理器

### 安装依赖

```bash
pnpm install
```

### 开发命令

```bash
# 开发模式
pnpm dev

# 构建项目
pnpm build

# 代码检查
pnpm lint
```

### 构建说明

项目使用多配置构建方式，分别构建：

- 内容脚本 (content script)
- 后台脚本 (background script)
- 弹出窗口 (popup)

## 浏览器兼容性

- Chrome >= 88
- Edge >= 88 (基于 Chromium)
- 其他基于 Chromium 的浏览器 (版本要求同上)
