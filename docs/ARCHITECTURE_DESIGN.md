# 🏗️ Chrome 阅读插件架构设计文档

> 📅 **版本**: v1.0
> 🎯 **目标**: 统一架构，实现现代化设计系统

## 🎯 技术决策

### 主导技术栈

- **UI 组件系统**: Shadcn/UI (基于 Radix UI)
- **样式系统**: Tailwind CSS 4
- **状态管理**: Zustand
- **开发语言**: TypeScript (严格模式)
- **构建工具**: Vite
- **包管理器**: pnpm

### 架构原则

1. **单一数据源**: 所有状态统一管理
2. **组件化设计**: 可复用、可组合的组件
3. **设计系统驱动**: 严格遵循设计规范
4. **性能优先**: 优化加载和渲染性能
5. **无障碍友好**: 完整的可访问性支持

## 🏛️ 架构层次

### 1. 表现层 (Presentation Layer)

```
src/
├── components/ui/          # Shadcn/UI 基础组件
├── popup/                  # Popup 界面
├── content/ui/             # 内容脚本 UI
└── content/components/     # 阅读模式组件
```

### 2. 业务逻辑层 (Business Logic Layer)

```
src/
├── features/               # 业务功能模块
├── store/                  # 状态管理
└── services/               # 业务服务
```

### 3. 数据层 (Data Layer)

```
src/
├── storage/                # 数据存储
├── types/                  # 类型定义
└── constants/              # 常量定义
```

### 4. 基础设施层 (Infrastructure Layer)

```
src/
├── utils/                  # 工具函数
├── lib/                    # 第三方库封装
└── background/             # 后台脚本
```

## 🎨 设计系统规范

### 组件使用规范

1. **优先使用 Shadcn/UI 组件**
2. **自定义组件必须继承 Shadcn/UI 设计语言**
3. **禁止使用原生 DOM 操作创建 UI**
4. **所有组件必须支持 TypeScript**

### 样式系统规范

1. **优先使用 Tailwind CSS 类**
2. **使用设计令牌定义颜色和间距**
3. **实现响应式设计**
4. **支持主题切换**

### 状态管理规范

1. **使用 Zustand 进行状态管理**
2. **状态必须类型安全**
3. **实现状态持久化**
4. **支持状态同步**
