# 阅读插件 v1.5.1 更新日志

## 概述

v1.5.1 版本是一次重要的技术升级，主要专注于提升内容提取的准确性、增强图片处理能力、优化代码块显示效果，以及提高整体安全性。这些改进基于 Obsidian Clipper 的设计理念和技术方案，使阅读插件更加成熟、稳定和高效。

## 主要改进

### 1. 内容提取升级

- **Defuddle 集成**：替换 Mozilla Readability 为更强大的 Defuddle 内容提取库
  - 更准确的内容识别，特别是对复杂布局的网页
  - 更好地保留原始内容的结构和格式
  - 更智能地处理特殊内容（如代码块、数学公式、脚注等）
  - 提取更多元数据，包括作者、发布日期等

- **降级机制**：当 Defuddle 提取失败时，自动回退到 Readability
  - 确保内容提取的稳定性和可靠性
  - 无缝切换，用户无感知

### 2. 内容安全增强

- **DOMPurify 集成**：添加专业的 HTML 净化工具
  - 移除潜在的恶意代码，防止 XSS 攻击
  - 保留有用的 HTML 结构和样式
  - 确保提取的内容安全可靠

- **安全配置优化**：
  - 精细控制允许的 HTML 标签和属性
  - 为不同类型的内容设置不同的安全级别
  - 添加自定义钩子，处理特殊情况

### 3. 图片处理优化

- **增强型媒体提取器**：全面升级图片处理能力
  - 更强大的懒加载图片检测，支持几乎所有主流懒加载方案
  - 智能处理背景图片，将其转换为普通图片
  - 优化 noscript 标签中的图片提取
  - 更好的图片加载状态指示

- **图片加载优化**：
  - 使用 IntersectionObserver 实现更高效的懒加载
  - 添加平滑的加载过渡效果
  - 优化图片占位符设计，提供更好的用户体验

### 4. 代码块显示优化

- **GitHub 风格代码块**：全新设计的代码块样式
  - 更加符合 GitHub 的设计语言
  - 工具栏、行号和代码内容区域视觉统一
  - 深色/浅色主题下保持一致的设计

- **代码高亮增强**：
  - 优化代码高亮配置，提高语言检测准确性
  - 添加行高亮功能，方便阅读重要代码
  - 改进代码块工具栏，使其更加直观易用

### 5. 整体用户体验提升

- **CSS 变量系统重构**：
  - 更加系统化的变量命名和组织
  - 确保深色/浅色主题下的一致性
  - 更好的组件样式隔离

- **性能优化**：
  - 减少不必要的 DOM 操作
  - 优化资源加载顺序
  - 添加缓存机制，提高重复访问的速度

## 技术细节

### 新增依赖

- **defuddle**: 用于内容提取，替代 Mozilla Readability
- **dompurify**: 用于 HTML 净化，提高安全性

### 新增文件

- **src/content/extractors/defuddleExtractor.ts**: Defuddle 内容提取器
- **src/content/extractors/enhancedMediaExtractor.ts**: 增强型媒体提取器
- **src/utils/sanitizer.ts**: HTML 净化工具
- **src/content/styles/github-code.css**: GitHub 风格代码块样式

### 修改文件

- **src/content/extractors/index.ts**: 更新提取器导出
- **src/content/content.ts**: 使用新的提取器和样式
- **package.json**: 添加新依赖

## 已知问题

- 在某些特殊网站上，Defuddle 可能提取不完整，此时会自动回退到 Readability
- 极少数情况下，增强型媒体提取器可能无法正确处理某些特殊的懒加载图片
- 某些网站使用非标准的代码块格式，可能导致代码高亮不完全准确

**注意：** Defuddle 库需要使用默认导入方式，而非命名导入：
```javascript
// 正确的导入方式
import Defuddle from 'defuddle';

// 错误的导入方式
// import { Defuddle } from 'defuddle';
```
