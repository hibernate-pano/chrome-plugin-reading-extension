# Folio v3.4.0

极简阅读扩展，专注正文。本版新增**一键导出 PDF（A4 排版）**。

## 📄 一键导出 PDF

阅读模式工具栏新增下载按钮，在新标签页以 A4 排版输出当前文章。

**排版**

- A4 纸张，页边距上下 20mm / 左右 18mm，正文宽 174mm（每行约 44 个汉字）
- 借用 Chrome 排版引擎输出 —— **文字可选中、可搜索**，5 千字文章约数百 KB
- 零新增运行时依赖

**可调项**（均被记住）

- 纸张主题：浅色 / 护眼（刻意不提供深色：整页黑底打印费墨且对比度差）
- 字号：9 / 10.5 / 11 / 12 / 13pt
- 图片大小：大 / 中 / 小

**排版细节**

- 标题不落在页底，段落控制孤行
- 代码块按渲染高度分档：短的整块保留，长的允许跨页
- 图片永不从中间切断，超高图自动缩放到一页内
- 宽表格压在 174mm 内，不横向溢出

**稳健性**

- 修复懒加载图片（识别透明占位图，从 `data-src` 等懒加载属性回填真实地址）
- 打印前等待图片解码（上限 5 秒），失败时如实告知数量，而非静默输出空白框
- 打印页不执行文章内的任何脚本；来源链接仅接受 http(s)

## 🖨 已知限制

- **预览页是连续滚动，不提供分页预览。** 浏览器没有分页查询 API，自行模拟的断页
  与实际输出必然有偏差。精确分页请用 Chrome 打印对话框的预览。
- **打印对话框请保持**：纸张 A4、边距「默认」、缩放 100%。打印机默认可能是
  Letter（比 A4 矮 18mm），会整体改变分页。
- **图片处可能留白**：图放不下当前页时会整体挪到下一页。已通过限制图片高度、
  允许超长代码块跨页把留白收敛，但无法消除（除非允许图片被切半）。
- **需登录才能访问的图片会失败**：扩展不携带目标站点的 Cookie。
- **只提供 `srcset` 的图片会打印为空白**：懒加载回填只读 `data-src` 这类属性。
  `srcset` 在 HTML 消毒阶段就被整体剥离（页面可以用它决定加载哪些像素、
  花多少流量，这不是读者该替页面做的决定），所以回填阶段拿不到它。
  绝大多数站点同时给 `src`，那种情况不受影响。

## ⚠️ v3.3.0 的破坏性变更

- **移除 popup 界面**：点击扩展图标现在**直接切换阅读模式**，不再是弹出面板
- **移除 32 套主题**：收敛为浅色 / 深色 / 护眼三套
- **移除 TTS 朗读、收藏夹、夜间模式自动切换、Markdown/HTML 导出**
- 代码量从 5.7k 行降至 3.3k 行

## 📦 安装

1. 下载下方的 `folio-reader-v3.4.0.zip` 并解压
2. 打开 `chrome://extensions/`
3. 启用右上角**开发者模式**
4. 点击**加载已解压的扩展程序**，选择解压后的文件夹
5. 工具栏出现 Folio 图标

> ⚠️ zip 需**先解压**再加载，Chrome 不支持直接加载压缩包。

## 🖥️ 浏览器要求

Chrome / Edge 114+（Manifest V3 + chrome.storage.session）
