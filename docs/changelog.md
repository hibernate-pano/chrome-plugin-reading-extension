# 变更日志 (Changelog)

本文档记录项目的所有重要变更。

## [1.5.1] - 2024-05-10

### 基于 Obsidian Clipper 的设计改进

#### CSS 变量系统重构
- 重新组织 CSS 变量，使用更加系统化的命名约定
- 将颜色变量分为基础色、语义色和组件色三个层级
- 确保所有组件都使用变量，而非硬编码颜色值

#### 代码块重设计
- 简化代码块容器设计，移除过度装饰
- 优化工具栏和行号区域，使其更加低调
- 确保代码主题正确应用到所有部分
- 使用更微妙的阴影和过渡效果

#### 内容容器优化
- 重新设计阅读容器，使用动态计算的内边距
- 优化内容宽度和间距，确保在不同屏幕尺寸下有适当的留白
- 移除过度的装饰，专注于内容本身

#### 排版与文本处理优化
- 使用系统字体栈，减少加载额外字体的性能开销
- 优化文本渲染，提高可读性
- 改进引用块设计，使用更加简洁的样式

#### 图片处理优化
- 简化图片容器设计，移除缩放和下载按钮
- 使用更加微妙的悬停效果
- 优化图片加载状态和过渡效果

#### 交互与反馈优化
- 简化滚动条设计，使其更加低调
- 优化文字选择高亮颜色
- 优化工具栏设计和交互
- 添加微妙的过渡效果

## [1.5.0] - 2024-04-18

### 极简主义代码块设计

#### GitHub 风格代码块设计
- 采用 GitHub 的字体系列和设计风格，提供更加一致的用户体验
- 简化工具栏和按钮设计，移除多余的视觉元素，使其更加简洁
- 工具栏字体大小与代码内容保持一致，提供更加协调的视觉效果
- 优化行号区域的设计，使其与 GitHub 的设计风格保持一致
- 使用 GitHub 的颜色方案，包括暗色和亮色主题

#### 代码宽度处理优化
- 添加换行模式切换功能，允许用户在水平滚动和自动换行模式之间切换
- 默认使用水平滚动模式，保持代码原有格式
- 按钮状态变化提供明确的视觉反馈
- 在移动设备上优化按钮样式，提供更好的响应式体验

#### 代码块工具栏重新设计
- 将工具栏从代码块底部移到顶部，提高可发现性
- 工具栏始终可见，不需要悬停才能显示，增强直观性
- 复制按钮添加文本标签“复制”，功能更加明确
- 优化复制成功提示的位置和样式，使其更加简洁和直观

#### 交互体验优化
- 点击复制按钮后，显示悬浮提示，并更新按钮文本
- 鼠标悬停时增加行号的不透明度，提供更好的视觉反馈
- 根据代码语言应用特定的样式，提供更加直观的视觉区分

#### 响应式设计增强
- 在小屏幕设备上自动隐藏行号，调整布局为单列
- 优化工具栏在移动设备上的显示，确保按钮和标签清晰可见
- 调整字体大小和内边距，确保在小屏幕上的可读性

### 修复重复进入阅读模式问题

#### 状态管理改进
- 增强了阅读模式状态管理，避免重复进入阅读模式
- 在 `enableReadingMode` 函数开始时检查是否已经处于阅读模式
- 在 `disableReadingMode` 函数开始时检查是否处于阅读模式
- 完全重置状态，确保退出阅读模式后所有状态都被正确清理

#### 代码块处理优化
- 改进了代码块处理逻辑，确保在重复进入阅读模式时能够正确处理代码块
- 增强了代码块容器的清理逻辑，彻底清除所有已存在的增强代码块容器
- 添加了更详细的日志输出，便于调试和问题排查
- 清除可能存在的其他代码相关元素，如代码头部和复制按钮

#### 资源清理增强
- 改进了退出阅读模式时的资源清理逻辑
- 清除所有事件监听器，包括滚动、键盘、调整大小和点击事件
- 清除可能存在的定时器，避免定时器泄漏
- 重置样式元素，但不添加内容，避免样式冲突

#### 错误处理增强
- 增强了错误处理逻辑，确保即使在出错的情况下也能正确清理资源
- 添加了更详细的错误日志，便于问题排查
- 使用 try-catch 块包裹关键操作，确保一个操作的失败不会影响整个流程

### 图片加载优化

#### 懒加载图片处理改进
- 扩展了懒加载属性检测范围，支持更多类型的懒加载实现
- 添加了对 noscript 标签中图片的检测
- 增强了对父元素背景图片的检测
- 添加了对 srcset 属性的处理

#### 图片占位符重新设计
- 使用渐变背景和动画效果替代静态背景色
- 实现了"闪烁"(shimmer)效果，提供更好的视觉反馈
- 优化了加载动画的大小和颜色，使其更加低调
- 增加了圆角，与图片容器保持一致

#### 加载过渡效果优化
- 实现了图片加载完成后的平滑淡入效果
- 添加了轻微的缩放效果，使图片加载更加生动
- 优化了占位符的淡出效果，避免突然消失
- 实现了图片预加载机制，使用新的 Image 对象

#### 图片容器样式优化
- 为图片容器添加了轻微的阴影效果
- 实现了悬停时的阴影增强效果
- 优化了暗色模式下的容器样式
