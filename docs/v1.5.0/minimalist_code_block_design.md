# 极简主义代码块设计

## 概述

本文档详细说明了对阅读插件中代码块样式的全新设计，采用极简主义风格，摒弃了传统的卡片式设计，专注于代码内容的呈现，同时提供直观的交互功能。

## 设计理念

1. **极简主义**：移除多余的视觉元素，专注于代码内容的呈现
2. **无边界设计**：摒弃传统的卡片式设计，采用更加开放的布局
3. **上下文感知**：工具栏只在需要时显示，减少视觉干扰
4. **直观交互**：提供简单直观的交互方式，如复制代码、查看语言信息等
5. **响应式设计**：在不同设备上都能提供良好的用户体验

## 技术实现

### HTML结构

采用全新的HTML结构，使用CSS Grid布局实现更加灵活的排版：

```html
<div class="code-block lang-javascript" data-lines="6">
  <!-- 行号区域 -->
  <div class="line-numbers">
    <span class="line-number">1</span>
    <span class="line-number">2</span>
    <!-- 更多行号... -->
  </div>
  
  <!-- 代码内容区域 -->
  <pre class="code-content">
    <code class="language-javascript hljs">
      <!-- 高亮后的代码内容 -->
    </code>
  </pre>
  
  <!-- 工具栏 -->
  <div class="code-toolbar">
    <span class="code-language">JavaScript</span>
    <span class="code-caption">示例代码</span>
    <button class="code-copy-button" title="复制代码">
      <!-- SVG图标 -->
    </button>
  </div>
</div>
```

### CSS设计

使用CSS Grid布局，实现更加灵活的排版：

```css
.code-block {
  position: relative;
  margin: 2em 0;
  display: grid;
  grid-template-columns: auto 1fr;
  grid-template-rows: 1fr auto;
}

.line-numbers {
  grid-column: 1;
  grid-row: 1;
}

.code-content {
  grid-column: 2;
  grid-row: 1;
}

.code-toolbar {
  grid-column: 1 / span 2;
  grid-row: 2;
}
```

### 交互设计

1. **上下文感知的工具栏**：工具栏默认隐藏，只在鼠标悬停时显示
2. **复制功能优化**：点击复制按钮后，显示悬浮提示，而不是改变按钮文本
3. **行号交互**：鼠标悬停时增加行号的不透明度，提供更好的视觉反馈
4. **响应式设计**：在小屏幕设备上自动隐藏行号，调整布局为单列

## 主要特性

### 1. 无边界设计

摒弃了传统的卡片式设计，采用更加开放的布局，减少视觉边界，让代码内容更加突出。代码区域和行号区域使用微妙的边框和背景色区分，而不是使用明显的卡片边界。

### 2. 上下文感知的工具栏

工具栏默认隐藏（低不透明度），只在鼠标悬停时显示，减少视觉干扰。工具栏包含语言标签、代码标题（如果有）和复制按钮，提供必要的功能而不占用过多空间。

### 3. 简化的复制功能

复制按钮只显示图标，不显示文本，减少视觉干扰。点击复制按钮后，显示悬浮提示，而不是改变按钮文本，提供更加直观的反馈。

### 4. 优化的行号显示

行号区域使用与代码区域相同的背景色，但使用不同的边框颜色区分。行号默认低不透明度，鼠标悬停时增加不透明度，提供更好的视觉反馈。

### 5. 响应式设计

在小屏幕设备上自动隐藏行号，调整布局为单列，确保在移动设备上也能提供良好的用户体验。

### 6. 语言特定样式

根据代码语言应用特定的样式，如JavaScript代码的语言标签使用黄色，TypeScript使用蓝色等，提供更加直观的视觉区分。

## 主题支持

代码块设计支持亮色和暗色两种主题，通过CSS变量实现主题切换：

```css
/* 暗色主题变量 */
.dark-theme {
  --code-border: #30363d;
  --code-language-color: #8b949e;
  /* 更多变量... */
}

/* 亮色主题变量 */
.light-theme {
  --code-border: #d0d7de;
  --code-language-color: #57606a;
  /* 更多变量... */
}
```

## 与旧版本的对比

### 旧版本（卡片式设计）

1. 使用明显的卡片边界，包括边框、圆角和阴影
2. 头部和内容区域使用不同的背景色，视觉上分离
3. 语言标签使用背景色，视觉上突出
4. 工具栏始终可见，占用空间
5. 复制按钮包含文本和图标，占用更多空间

### 新版本（极简主义设计）

1. 移除卡片边界，使用微妙的边框和背景色区分区域
2. 所有区域使用相同的背景色，视觉上统一
3. 语言标签移除背景色，使用颜色区分不同语言
4. 工具栏默认隐藏，只在需要时显示
5. 复制按钮只显示图标，减少视觉干扰

## 用户体验改进

1. **减少视觉干扰**：移除多余的视觉元素，让用户更加专注于代码内容
2. **提高可读性**：优化代码字体、行高和颜色方案，提高代码可读性
3. **简化交互**：提供简单直观的交互方式，如复制代码、查看语言信息等
4. **响应式设计**：在不同设备上都能提供良好的用户体验
5. **主题支持**：支持亮色和暗色两种主题，适应不同的阅读环境
