# v1.5.0 测试计划

本文档详细说明了 v1.5.0 版本的测试计划，主要聚焦于验证重复进入阅读模式问题的修复。

## 1. 重复进入阅读模式测试

### 1.1 基本功能测试

**测试目标**：验证阅读模式的基本功能是否正常工作

**测试步骤**：
1. 打开一个包含文本、图片和代码块的网页
2. 点击扩展图标，进入阅读模式
3. 验证页面内容是否正确显示
4. 验证代码块是否正确高亮
5. 验证图片是否正确显示
6. 点击退出按钮，退出阅读模式
7. 验证页面是否恢复原始状态

**预期结果**：
- 阅读模式能够正常进入和退出
- 页面内容在阅读模式下正确显示
- 代码块正确高亮
- 图片正确显示
- 退出阅读模式后页面恢复原始状态

### 1.2 重复进入测试

**测试目标**：验证重复进入阅读模式是否不会导致问题

**测试步骤**：
1. 打开一个包含文本、图片和代码块的网页
2. 点击扩展图标，进入阅读模式
3. 再次点击扩展图标，确认不会重复进入阅读模式
4. 点击退出按钮，退出阅读模式
5. 再次点击扩展图标，进入阅读模式
6. 验证页面内容是否正确显示
7. 验证代码块是否正确高亮
8. 验证图片是否正确显示
9. 重复步骤 4-8 多次

**预期结果**：
- 已经处于阅读模式时，再次点击扩展图标不会导致重复进入
- 多次进入退出阅读模式后，页面内容、代码块和图片仍能正确显示
- 不会出现代码块渲染失败或样式问题

### 1.3 快速切换测试

**测试目标**：验证快速切换阅读模式是否不会导致问题

**测试步骤**：
1. 打开一个包含文本、图片和代码块的网页
2. 快速连续点击扩展图标和退出按钮，进行多次快速切换
3. 在最后一次进入阅读模式后，验证页面内容是否正确显示
4. 验证代码块是否正确高亮
5. 验证图片是否正确显示

**预期结果**：
- 快速切换阅读模式不会导致页面内容、代码块或图片显示问题
- 不会出现代码块渲染失败或样式问题

## 2. 代码块渲染测试

### 2.1 多种语言代码块测试

**测试目标**：验证不同语言的代码块是否能够正确高亮

**测试步骤**：
1. 打开一个包含多种语言代码块的网页（如 JavaScript、Python、HTML、CSS 等）
2. 点击扩展图标，进入阅读模式
3. 验证每种语言的代码块是否正确高亮
4. 退出阅读模式后再次进入
5. 再次验证代码块高亮

**预期结果**：
- 不同语言的代码块都能正确高亮
- 重复进入阅读模式后代码块仍能正确高亮

### 2.2 大型代码块测试

**测试目标**：验证大型代码块是否能够正确渲染

**测试步骤**：
1. 打开一个包含大型代码块（超过 100 行）的网页
2. 点击扩展图标，进入阅读模式
3. 验证大型代码块是否正确高亮和显示
4. 退出阅读模式后再次进入
5. 再次验证大型代码块的渲染

**预期结果**：
- 大型代码块能够正确高亮和显示
- 重复进入阅读模式后大型代码块仍能正确渲染

## 3. 图片处理测试

### 3.1 懒加载图片测试

**测试目标**：验证懒加载图片是否能够正确显示

**测试步骤**：
1. 打开一个包含懒加载图片的网页
2. 点击扩展图标，进入阅读模式
3. 滚动页面，验证懒加载图片是否正确显示
4. 退出阅读模式后再次进入
5. 再次验证懒加载图片的显示

**预期结果**：
- 懒加载图片能够正确显示
- 重复进入阅读模式后懒加载图片仍能正确显示

### 3.2 图片控制测试

**测试目标**：验证图片显示控制是否正常工作

**测试步骤**：
1. 打开一个包含图片的网页
2. 点击扩展图标，进入阅读模式
3. 在设置面板中关闭图片显示
4. 验证图片是否正确隐藏
5. 再次开启图片显示
6. 验证图片是否正确显示
7. 退出阅读模式后再次进入
8. 验证图片显示状态是否与设置一致

**预期结果**：
- 图片显示控制能够正常工作
- 重复进入阅读模式后图片显示状态与设置一致

## 4. 性能测试

### 4.1 内存使用测试

**测试目标**：验证重复进入阅读模式是否不会导致内存泄漏

**测试步骤**：
1. 打开开发者工具，切换到性能或内存标签
2. 记录初始内存使用情况
3. 多次进入和退出阅读模式（至少 10 次）
4. 记录最终内存使用情况
5. 比较初始和最终内存使用情况

**预期结果**：
- 多次进入和退出阅读模式后，内存使用不会显著增加
- 不会出现内存泄漏

### 4.2 响应时间测试

**测试目标**：验证重复进入阅读模式是否不会导致响应时间增加

**测试步骤**：
1. 打开开发者工具，切换到性能标签
2. 记录首次进入阅读模式的响应时间
3. 退出阅读模式后再次进入
4. 记录第二次进入阅读模式的响应时间
5. 重复步骤 3-4 多次
6. 比较各次进入阅读模式的响应时间

**预期结果**：
- 重复进入阅读模式的响应时间不会显著增加
- 各次进入阅读模式的响应时间基本一致

## 5. 兼容性测试

### 5.1 浏览器兼容性测试

**测试目标**：验证修复在不同浏览器上是否有效

**测试步骤**：
1. 在 Chrome 浏览器上执行上述所有测试
2. 在 Edge 浏览器上执行上述所有测试
3. 在其他基于 Chromium 的浏览器上执行上述所有测试

**预期结果**：
- 修复在所有测试的浏览器上都有效
- 不会出现浏览器特定的问题

### 5.2 设备兼容性测试

**测试目标**：验证修复在不同设备上是否有效

**测试步骤**：
1. 在桌面设备上执行上述所有测试
2. 在移动设备上执行上述所有测试（使用开发者工具的设备模拟功能）

**预期结果**：
- 修复在所有测试的设备上都有效
- 不会出现设备特定的问题
