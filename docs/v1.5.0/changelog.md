# 变更日志 (Changelog)

## [1.5.0] - 2024-04-18

### 修复重复进入阅读模式问题

#### 状态管理改进
- 增强了阅读模式状态管理，避免重复进入阅读模式
- 在 `enableReadingMode` 函数开始时检查是否已经处于阅读模式
- 在 `disableReadingMode` 函数开始时检查是否处于阅读模式
- 完全重置状态，确保退出阅读模式后所有状态都被正确清理

#### 代码块处理优化
- 改进了代码块处理逻辑，确保在重复进入阅读模式时能够正确处理代码块
- 增强了代码块容器的清理逻辑，彻底清除所有已存在的增强代码块容器
- 添加了更详细的日志输出，便于调试和问题排查
- 清除可能存在的其他代码相关元素，如代码头部和复制按钮

#### 资源清理增强
- 改进了退出阅读模式时的资源清理逻辑
- 清除所有事件监听器，包括滚动、键盘、调整大小和点击事件
- 清除可能存在的定时器，避免定时器泄漏
- 重置样式元素，但不添加内容，避免样式冲突

#### 错误处理增强
- 增强了错误处理逻辑，确保即使在出错的情况下也能正确清理资源
- 添加了更详细的错误日志，便于问题排查
- 使用 try-catch 块包裹关键操作，确保一个操作的失败不会影响整个流程

### 图片加载优化

#### 懒加载图片处理改进
- 扩展了懒加载属性检测范围，支持更多类型的懒加载实现
- 添加了对 noscript 标签中图片的检测
- 增强了对父元素背景图片的检测
- 添加了对 srcset 属性的处理

#### 图片占位符重新设计
- 使用渐变背景和动画效果替代静态背景色
- 实现了"闪烁"(shimmer)效果，提供更好的视觉反馈
- 优化了加载动画的大小和颜色，使其更加低调
- 增加了圆角，与图片容器保持一致

#### 加载过渡效果优化
- 实现了图片加载完成后的平滑淡入效果
- 添加了轻微的缩放效果，使图片加载更加生动
- 优化了占位符的淡出效果，避免突然消失
- 实现了图片预加载机制，使用新的 Image 对象

#### 图片容器样式优化
- 为图片容器添加了轻微的阴影效果
- 实现了悬停时的阴影增强效果
- 优化了暗色模式下的容器样式
