# 变更日志 (Changelog)

## [1.5.0] - 2024-04-18

### 修复重复进入阅读模式问题

#### 状态管理改进
- 增强了阅读模式状态管理，避免重复进入阅读模式
- 在 `enableReadingMode` 函数开始时检查是否已经处于阅读模式
- 在 `disableReadingMode` 函数开始时检查是否处于阅读模式
- 完全重置状态，确保退出阅读模式后所有状态都被正确清理

#### 代码块处理优化
- 改进了代码块处理逻辑，确保在重复进入阅读模式时能够正确处理代码块
- 增强了代码块容器的清理逻辑，彻底清除所有已存在的增强代码块容器
- 添加了更详细的日志输出，便于调试和问题排查
- 清除可能存在的其他代码相关元素，如代码头部和复制按钮

#### 资源清理增强
- 改进了退出阅读模式时的资源清理逻辑
- 清除所有事件监听器，包括滚动、键盘、调整大小和点击事件
- 清除可能存在的定时器，避免定时器泄漏
- 重置样式元素，但不添加内容，避免样式冲突

#### 错误处理增强
- 增强了错误处理逻辑，确保即使在出错的情况下也能正确清理资源
- 添加了更详细的错误日志，便于问题排查
- 使用 try-catch 块包裹关键操作，确保一个操作的失败不会影响整个流程

### 图片加载优化

#### 懒加载图片处理改进
- 扩展了懒加载属性检测范围，支持更多类型的懒加载实现
- 添加了对 noscript 标签中图片的检测
- 增强了对父元素背景图片的检测
- 添加了对 srcset 属性的处理

#### 图片占位符重新设计
- 使用渐变背景和动画效果替代静态背景色
- 实现了"闪烁"(shimmer)效果，提供更好的视觉反馈
- 优化了加载动画的大小和颜色，使其更加低调
- 增加了圆角，与图片容器保持一致

#### 加载过渡效果优化
- 实现了图片加载完成后的平滑淡入效果
- 添加了轻微的缩放效果，使图片加载更加生动
- 优化了占位符的淡出效果，避免突然消失
- 实现了图片预加载机制，使用新的 Image 对象

#### 图片容器样式优化
- 为图片容器添加了轻微的阴影效果
- 实现了悬停时的阴影增强效果
- 优化了暗色模式下的容器样式

### 代码块重设计

#### 代码块容器优化
- 减小了边框圆角和阴影效果，使其更加低调
- 添加了细边框，增强了边界感但不过分突出
- 添加了平滑的悬停效果，轻微增强阴影
- 使用CSS变量定义边框颜色，确保主题一致性

#### 代码块头部优化
- 减小了标题栏内边距和整体字体大小
- 简化了语言标签的设计，减小了字体大小和内边距
- 添加了透明度和悬停效果，使其更加低调
- 优化了复制按钮的大小和视觉反馈

#### 代码内容区域优化
- 减小了内边距和优化了行高
- 减小了滚动条大小，添加了圆角和透明度
- 添加了字母间距，提高可读性
- 优化了代码字体和显示效果

#### 行号区域优化
- 减小了行号区域宽度和字体大小
- 降低了分隔线的不透明度，减少视觉干扰
- 降低了行号的默认不透明度，添加了平滑的过渡效果
- 优化了行号与代码内容的视觉平衡

#### 内联代码优化
- 减小了字体大小和内边距
- 添加了字母间距和过渡效果
- 优化了边框和背景色，使其更加协调

#### 响应式布局优化
- 为移动设备优化了代码块容器样式
- 减小了各元素的大小和间距
- 优化了行号区域在小屏幕上的显示

### 真正的单卡片代码块设计

#### HTML结构重构
- 将原来的分离式结构改为嵌套式结构，彻底消除堆叠感
- 创建内容包装器（`code-content-wrapper`）统一管理代码块内容
- 将原来的头部（`code-header`）改为顶部栏（`code-top-bar`）

#### 容器统一
- 为整个代码块容器设置统一的样式
- 使用单一背景色，消除内外层的视觉差异
- 简化边框和阴影效果，使其更加融入页面

#### 顶部栏与内容区域统一
- 使顶部栏和内容区域使用相同的背景色，视觉上完全统一
- 简化边框，仅保留底部边框，减少视觉层次
- 移除语言标签的背景色，使其更加低调和融入

#### 代码内容区域优化
- 调整内容区域的内边距，使其与顶部栏更加协调
- 移除内容区域的顶部边框，确保与顶部栏视觉上连贯
- 优化滚动条样式，使其更加低调

#### 行号区域优化
- 更新行号区域的选择器，使其与新的HTML结构一致
- 优化行号的视觉效果，使其更加低调
