# v1.5.0 第一阶段实施计划

本文档详细说明了 v1.5.0 版本第一阶段的实施计划，主要聚焦于修复关键问题、界面简化和视觉设计优化。

## 1. 修复关键问题

### 1.1 代码高亮问题修复

**当前问题**：
- 代码高亮功能不稳定
- 重复进入阅读模式导致代码高亮失效
- 代码主题应用不正确，特别是在暗色模式下

**解决方案**：
1. 重构代码高亮实现逻辑
2. 优化 highlight.js 的使用方式
3. 添加更健壮的错误处理和回退机制
4. 确保代码主题在所有模式下正确应用

**相关文件**：
- `src/content/extractors/codeExtractor.ts`
- `src/content/styles/codeblock.css`

### 1.2 懒加载图片处理优化

**当前问题**：
- 懒加载图片在阅读模式下无法正确显示
- 图片占位符设计不够简洁

**解决方案**：
1. 扩展懒加载属性检测范围
2. 优化 IntersectionObserver 实现
3. 设计简约的图片占位符，不使用文字标签
4. 添加平滑的图片加载过渡效果

**相关文件**：
- `src/content/extractors/mediaExtractor.ts`
- `src/content/content.ts` (handleMediaElements 函数)

### 1.3 重复进入阅读模式问题修复

**当前问题**：
- 重复进入阅读模式导致代码块渲染失败和页面样式问题

**解决方案**：
1. 实现更健壮的状态管理
2. 添加清理机制，确保每次进入前正确清理之前的状态
3. 优化 DOM 操作，减少冲突

**相关文件**：
- `src/content/content.ts` (enableReadingMode 和 disableReadingMode 函数)

## 2. 界面简化

### 2.1 设置面板重设计

**当前问题**：
- 设置面板元素较多，可能让用户感到复杂
- 缺少设置重置功能

**解决方案**：
1. 重新组织设置项，使用分组和层级结构
2. 将不常用选项移至高级设置区域
3. 添加设置重置按钮
4. 优化控件布局和间距

**相关文件**：
- `src/popup/Popup.tsx`
- `src/ui/components/Card.tsx`
- `src/ui/components/Tabs.tsx`

### 2.2 扩展图标行为优化

**当前问题**：
- 扩展图标点击行为不够直观

**解决方案**：
1. 非阅读模式下点击直接进入阅读模式
2. 阅读模式下点击打开设置面板
3. 添加状态指示和过渡效果

**相关文件**：
- `src/background/background.ts`
- `src/content/content.ts`

### 2.3 移除不常用功能

**当前问题**：
- 图片缩放和下载功能不常用，增加了界面复杂度

**解决方案**：
1. 移除图片控件相关代码
2. 简化图片容器实现
3. 优化图片悬停效果

**相关文件**：
- `src/content/extractors/mediaExtractor.ts`

## 3. 视觉设计优化

### 3.1 代码块重设计

**当前问题**：
- 代码块样式存在堆叠感问题
- 代码块与整体设计不协调

**解决方案**：
1. 创建新的代码块样式，采用更集成的设计
2. 简化语言标签和复制按钮设计
3. 优化行号区域，减少视觉干扰
4. 确保与整体设计风格一致

**相关文件**：
- `src/content/styles/codeblock.css`
- `src/content/extractors/codeExtractor.ts`

### 3.2 暗色模式优化

**当前问题**：
- 暗色模式下某些元素对比度不够

**解决方案**：
1. 调整暗色模式的颜色方案
2. 提高文本与背景对比度
3. 优化 UI 元素在暗色模式下的可见性
4. 确保所有状态的颜色一致性

**相关文件**：
- `src/content/utils.ts`
- `src/content/content.css`
- `src/content/styles/codeblock.css`
- `src/content/styles/list.css`

### 3.3 页面宽度调整

**当前问题**：
- 默认页面宽度不够优化
- 超宽屏幕上内容过度拉伸

**解决方案**：
1. 将默认页面宽度设为 1200px
2. 设置最大宽度为 1800px
3. 优化响应式布局

**相关文件**：
- `src/content/utils.ts`
- `src/storage/storage.ts`

## 实施顺序

为了确保平稳过渡和减少风险，建议按以下顺序实施：

1. 首先修复关键问题：
   - 重复进入阅读模式问题
   - 代码高亮问题
   - 懒加载图片处理

2. 然后进行视觉设计优化：
   - 代码块重设计
   - 暗色模式优化
   - 页面宽度调整

3. 最后进行界面简化：
   - 移除不常用功能
   - 扩展图标行为优化
   - 设置面板重设计

## 测试计划

每个修改完成后，应进行以下测试：

1. **功能测试**：确保修改后的功能正常工作
2. **兼容性测试**：在不同浏览器和设备上测试
3. **性能测试**：确保修改不会导致性能下降
4. **用户体验测试**：收集用户反馈，确保改进符合用户期望

## 版本发布计划

完成所有修改并通过测试后，将发布 v1.5.0 版本，主要亮点包括：

1. 更稳定的代码高亮功能
2. 优化的图片处理
3. 简化的界面
4. 改进的暗色模式
5. 优化的页面宽度设置

## 下一步计划

完成 v1.5.0 版本后，将开始规划 v1.6.0 版本，重点关注第二阶段的功能增强：

1. 图片处理进一步优化
2. 代码块功能增强
3. 设置系统改进
4. 初步性能优化
