# 真正的单卡片代码块设计测试计划

## 测试目标

验证真正的单卡片代码块设计的有效性，特别是通过HTML结构重构彻底消除堆叠感、统一视觉设计、优化颜色方案和改进响应式布局等方面的改进。

## 测试环境

- **浏览器**：Chrome 最新版、Edge 最新版
- **设备**：桌面电脑、笔记本电脑、平板电脑（模拟）、手机（模拟）
- **主题**：亮色主题、暗色主题

## 测试用例

### 1. HTML结构验证

**测试目标**：验证代码块的HTML结构是否已经改为嵌套式结构，彻底消除堆叠感

**测试步骤**：
1. 打开一个包含代码块的网页
2. 点击扩展图标，进入阅读模式
3. 使用开发者工具检查代码块的HTML结构
4. 验证是否使用了新的嵌套式结构（`enhanced-code-container` > `code-content-wrapper` > `code-top-bar` + `pre`）
5. 在亮色和暗色主题下分别测试

**预期结果**：
- 代码块使用了新的嵌套式HTML结构
- 没有使用分离式结构（头部和内容区域分开）
- 在亮色和暗色主题下都使用了相同的HTML结构

### 2. 视觉堆叠感消除测试

**测试目标**：验证代码块是否完全消除了视觉上的堆叠感

**测试步骤**：
1. 打开一个包含代码块的网页
2. 点击扩展图标，进入阅读模式
3. 观察代码块的整体视觉效果
4. 检查是否存在任何视觉上的堆叠感或多层效果
5. 在亮色和暗色主题下分别测试

**预期结果**：
- 代码块呈现为单一卡片，完全没有堆叠感
- 顶部栏和内容区域视觉上完全统一，没有明显的分隔
- 在亮色和暗色主题下都没有堆叠感

### 3. 背景色统一测试

**测试目标**：验证代码块顶部栏和内容区域是否使用相同的背景色

**测试步骤**：
1. 打开一个包含代码块的网页
2. 点击扩展图标，进入阅读模式
3. 观察代码块顶部栏和内容区域的背景色
4. 使用开发者工具的颜色选择器验证背景色是否相同
5. 在亮色和暗色主题下分别测试

**预期结果**：
- 代码块顶部栏和内容区域使用完全相同的背景色
- 没有任何视觉上的背景色差异
- 在亮色和暗色主题下都有统一的背景色

### 4. 语言标签简化测试

**测试目标**：验证语言标签是否已简化，移除背景色

**测试步骤**：
1. 打开一个包含不同编程语言代码块的网页
2. 点击扩展图标，进入阅读模式
3. 观察语言标签的样式
4. 验证语言标签是否没有背景色
5. 在亮色和暗色主题下分别测试

**预期结果**：
- 语言标签没有背景色，视觉上更加低调
- 语言标签仍然清晰可见，能够识别代码语言
- 在亮色和暗色主题下都有良好的视觉效果

### 5. 边框连贯性测试

**测试目标**：验证代码块的边框是否连贯，内容区域是否没有顶部边框

**测试步骤**：
1. 打开一个包含代码块的网页
2. 点击扩展图标，进入阅读模式
3. 观察代码块的边框，特别是顶部栏和内容区域之间的边框
4. 验证内容区域是否没有顶部边框
5. 在亮色和暗色主题下分别测试

**预期结果**：
- 代码块只有一个外部边框，内部没有多余的边框
- 顶部栏和内容区域之间只有一个细边框，视觉上连贯
- 在亮色和暗色主题下都有良好的边框连贯性

### 6. 响应式布局测试

**测试目标**：验证代码块在不同屏幕尺寸下的显示效果

**测试步骤**：
1. 在桌面电脑上测试代码块显示效果
2. 在笔记本电脑上测试代码块显示效果
3. 使用开发者工具模拟平板电脑，测试代码块显示效果
4. 使用开发者工具模拟手机，测试代码块显示效果
5. 在各种设备上测试代码块的滚动和交互行为

**预期结果**：
- 代码块在各种屏幕尺寸下都有良好的显示效果
- 在小屏幕设备上，代码块元素大小和间距适当减小
- 代码块的滚动和交互行为在各种设备上都正常

### 7. 交互效果测试

**测试目标**：验证代码块的交互效果是否符合设计要求

**测试步骤**：
1. 将鼠标悬停在代码块上，观察悬停效果
2. 将鼠标悬停在语言标签上，观察透明度变化
3. 将鼠标悬停在复制按钮上，观察视觉反馈
4. 点击复制按钮，验证复制功能和成功反馈
5. 将鼠标悬停在行号上，观察行号的透明度变化

**预期结果**：
- 鼠标悬停在代码块上时，有轻微的阴影增强效果
- 鼠标悬停在语言标签上时，透明度增加
- 鼠标悬停在复制按钮上时，有明确的视觉反馈
- 点击复制按钮后，有成功复制的视觉反馈
- 鼠标悬停在行号上时，行号透明度增加

### 8. 多次进入退出测试

**测试目标**：验证多次进入退出阅读模式后代码块是否仍然正常显示

**测试步骤**：
1. 打开一个包含代码块的网页
2. 多次进入和退出阅读模式（至少5次）
3. 观察最后一次进入阅读模式时代码块的显示效果
4. 检查是否存在任何视觉上的堆叠感或多层效果
5. 在亮色和暗色主题下分别测试

**预期结果**：
- 多次进入退出后代码块仍然呈现为单一卡片，没有堆叠感
- 代码块的HTML结构和样式保持一致
- 在亮色和暗色主题下都有良好的显示效果
