# Folio v3.8.0

纯阅读、零干扰——把任意网页变成干净的阅读视图，并导出为 A4 排版的 PDF。
无服务器、无统计、仅 3 个运行时依赖，所有数据只存在你自己的浏览器里。

本版本的两条主线：**阅读器界面完成一轮 Google 原生方向的打磨**，以及
**打印页新增「无图」模式、并修复了一个自 v3.7.0 起就存在的图文重叠缺陷**。

---

## 📖 阅读器界面：Google 原生打磨

这一轮对阅读覆盖层做了系统的视觉与交互收敛，原则只有一条：
**控件像 Google 的产品，正文像一本书。**

- **Google 官方色板**：浅色 / 深色 / 护眼三主题全部改用 Google 灰阶与
  Google Blue 600（`#1a73e8`），与浏览器周边浑然一体
- **Material 设置面板**：主题色块带对勾与名称、填充式滑块、圆角卡片
- **历史面板**：计数徽章、更清晰的条目层级、隐私说明与清空入口
- **阅读进度条**：顶边细线，随滚动填充——Chrome 页面加载指示的同款位置
- **统一 snackbar**：导出失败等提示改为 Material 反色条，不再是刺眼的色块
- **恢复双簇工具栏**：关闭在左上、操作在右上，任何屏宽都不会遮挡正文；
  正文回到衬线字体，控件的 Google Sans 感不侵入阅读本身
- **焦点环只给键盘用户**：鼠标打开面板不再出现蓝色幽灵框

### 两个同构的渲染层根因

打磨过程中发现并修复了两个性质相同的缺陷，都指向同一类错误——
**样式离开了它的作用域**：

1. **阅读器**：设计令牌曾放在 `:root`，而阅读器样式表运行在 Shadow DOM
   里。`:root` 在 shadow 树中不匹配任何元素，全部令牌是死代码，浏览器对
   `var()` 失败的回退是属性初始值——字体、圆角、动效全错。令牌现已挂到
   阅读器根元素上。
2. **打印页**：每页切片克隆自测量文档，却脱离了 `.p-doc` / `.p-content`
   样式上下文。容器作用域的规则在纸上全部失效——图片按**自然尺寸**渲染，
   直接压住正文；标题回退到浏览器默认字号。该缺陷自 v3.7.0 起就存在于
   初始渲染，图片越大越明显，此前的小图验证夹具恰好掩盖了它。

两个修复都以真实 Chrome 探针复验：阅读器截图前后对比，打印页
7 场景 × 相邻块几何检测，重叠全部归零。

## 🖨 打印页新增「无图」模式

图片选项从三档扩为四档：**大 / 中 / 小 / 无图**。

- 无图时图片与图注一起离开版面，不留空盒；图文混排三页的文章压缩为
  一页纯文本
- 纯文本打印不再被慢速图床拖慢：无图启动直接跳过图片等待
- 从无图切回其他档位时，会先等图片就位再重新分页，不会围绕空白框切页

## 📦 安装

从 Chrome Web Store 安装，或在 `chrome://extensions` 开启开发者模式后
「加载已解压的扩展程序」选择本仓库的 `dist` 目录。

> Chrome 不支持直接加载压缩包，必须先解压再选 `dist` 目录。
>
> 浏览器要求：Chrome 102 或更高。

## 🖨 已知限制

这些**不是 bug**，但容易被误判为故障：

- **打印对话框请保持默认**：纸张 A4、边距「默认」、缩放 100%。分页由扩展
  决定，但打印机若换成 Letter（比 A4 矮 18mm），Chrome 仍会整体重排。
  **先看预览里的分页是否与打印对话框一致**，这是判断设置是否被改动的最快办法。
- **页面底部可能留白**：当页尾剩下的空间放不下下一张图或表格时，内容整体挪到
  下一页。这是刻意的——切开一张图比留白更糟。预览里能直接看到留白在哪。
- **需登录才能访问的图片会失败**：扩展不携带目标站点的 Cookie。
- **只提供 `srcset` 的图片会打印为空白**：`srcset` 在 HTML 消毒阶段就被整体
  剥离。绝大多数站点同时给 `src`，那种情况不受影响。
- **跨标签页的阅读历史仍可能丢记录**：每个标签页是独立的模块副本。彻底修复
  需要改存储布局，属于后续版本规划。

## 🔒 权限说明

| 权限                 | 用途                             |
| -------------------- | -------------------------------- |
| `storage`            | 保存主题、字号、阅读历史         |
| `activeTab` / `tabs` | 在当前标签页启用阅读模式         |
| `scripting`          | 按需注入阅读脚本                 |
| `<all_urls>`         | 读取文章正文。经扩展商店审核需要 |

不收集任何数据，无网络请求，无遥测。
