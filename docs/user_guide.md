# AI 阅读助手使用指南

## 简介

AI 阅读助手是一款专为提升网页阅读体验设计的 Chrome 扩展。它能够智能提取网页主要内容，移除干扰元素，并提供丰富的自定义选项，让您享受舒适、高效的阅读体验。

## 安装指南

### 从 Chrome 网上应用店安装

1. 访问 [Chrome 网上应用店](https://chrome.google.com/webstore)
2. 搜索"AI 阅读助手"
3. 点击"添加至 Chrome"按钮
4. 确认安装

### 手动安装（开发版）

1. 下载最新版本的扩展 ZIP 文件
2. 解压文件到本地文件夹
3. 打开 Chrome，访问 `chrome://extensions/`
4. 启用右上角的"开发者模式"
5. 点击"加载已解压的扩展程序"
6. 选择解压后的文件夹

## 基本使用

### 启用阅读模式

有两种方式可以启用阅读模式：

1. **通过扩展图标**：
   - 点击浏览器工具栏中的 AI 阅读助手图标
   - 在弹出窗口中点击"阅读模式"按钮

2. **通过快捷键**：
   - 默认快捷键：`Alt+R`（Windows/Linux）或 `Option+R`（Mac）
   - 可在 Chrome 扩展管理页面自定义快捷键

### 退出阅读模式

有三种方式可以退出阅读模式：

1. 点击页面右下角的"退出阅读模式"按钮
2. 再次点击扩展图标，然后点击"退出阅读模式"按钮
3. 使用与进入阅读模式相同的快捷键

## 功能详解

### 1. 基础设置

#### 阅读模式

启用或禁用阅读模式，将网页转换为优化的阅读视图。

#### 字体大小

调整正文文本的字体大小，范围从 12px 到 24px。

#### 背景颜色

选择阅读模式的背景颜色，提供以下选项：
- 纯白：标准白色背景
- 暖色：温暖的米黄色背景
- 冷色：淡蓝色背景
- 复古：传统纸张色背景
- 奶油：柔和的奶油色背景
- 薄荷：清新的薄荷绿背景
- 灰色：中性灰色背景

#### 字体选择

选择阅读模式使用的字体，提供以下选项：
- 系统默认：使用系统默认字体
- 宋体：传统中文宋体
- 黑体：中文黑体
- 楷体：中文楷体
- 苹方：苹果设备默认中文字体
- 微软雅黑：微软系统默认中文字体

#### 内容显示

- **显示图片**：控制是否显示文章中的图片
- **显示目录**：控制是否显示自动生成的文章目录

### 2. 样式设置

#### 字体间距

- **行高**：调整文本行的高度，影响行与行之间的紧密程度
- **行间距**：调整段落内文本行之间的间距
- **段落间距**：调整段落与段落之间的间距
- **字间距**：调整字符之间的间距

#### 页面布局

- **内容宽度**：调整阅读区域的宽度，范围从 600px 到 1200px
- **文本对齐**：选择文本的对齐方式（左对齐、居中、两端对齐）
- **首行缩进**：控制段落首行是否缩进

### 3. 高级设置

#### 代码显示

- **代码字体大小**：调整代码块的字体大小
- **代码主题**：选择代码高亮的主题样式，包括：
  - GitHub
  - One Dark
  - One Light
  - Material Dark
  - Material Light
  - Night Owl
  - Dracula
  - Solarized Dark
  - Solarized Light

### 4. 主题切换

在扩展弹出窗口的右上角，有一个开关可以在明亮和暗黑主题之间切换。

## 使用技巧

### 1. 优化阅读体验

- **选择合适的背景色**：根据环境光线选择合适的背景色，减少眼睛疲劳
- **调整字体大小**：根据设备和个人偏好调整合适的字体大小
- **使用适当的行间距**：较大的行间距有助于提高长文本的可读性
- **考虑禁用图片**：在阅读纯文本内容时，禁用图片可以减少干扰

### 2. 代码阅读优化

- **选择合适的代码主题**：根据个人偏好和环境选择代码主题
- **调整代码字体大小**：确保代码清晰可读
- **利用行号功能**：代码块自动显示行号，便于参考和讨论

### 3. 导航技巧

- **使用目录导航**：点击左侧目录可快速跳转到对应章节
- **在小屏幕设备上**：目录会自动隐藏，鼠标悬停在左侧边缘可显示目录

### 4. 性能考虑

- **大型页面**：对于特别长的页面，可能需要稍等片刻让阅读模式完全加载
- **图片处理**：如果页面包含大量图片，可以考虑禁用图片显示以提高性能

## 常见问题解答

### 1. 阅读模式无法正常工作

**可能原因**：
- 页面结构复杂，难以提取主要内容
- 页面使用了特殊的技术阻止内容提取
- 扩展权限不足

**解决方案**：
- 刷新页面后再尝试启用阅读模式
- 检查是否授予了扩展所需的权限
- 对于特定网站，可能需要等待扩展更新以支持

### 2. 设置没有保存

**可能原因**：
- 浏览器存储问题
- 扩展权限不足

**解决方案**：
- 确保浏览器允许扩展存储数据
- 重新安装扩展

### 3. 代码高亮不正确

**可能原因**：
- 代码语言未被正确识别
- 代码格式不规范

**解决方案**：
- 尝试不同的代码主题，可能有更好的识别效果
- 目前版本支持常见的编程语言，未来会增加更多语言支持

### 4. 目录生成不完整

**可能原因**：
- 页面标题结构不规范
- 标题层级混乱

**解决方案**：
- 目录基于页面的标题标签（h1-h6）生成，如果页面标题结构不规范，可能会影响目录生成
- 未来版本将改进目录生成算法

## 隐私说明

AI 阅读助手高度重视用户隐私：

- 所有处理都在本地进行，不会将页面内容发送到任何服务器
- 用户设置仅保存在浏览器本地存储中
- 扩展不会收集任何个人身份信息
- 扩展仅请求必要的权限来提供核心功能
