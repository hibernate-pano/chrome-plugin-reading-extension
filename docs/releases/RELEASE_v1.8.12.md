## 🎯 版本总结

经过 v1.8.9 到 v1.8.11 的多次迭代，v1.8.12 **终于彻底解决了阅读模式的核心问题**。

## 🐛 主要修复

### 解决 Popup 组件无限循环问题

**问题描述**：
- Popup 组件陷入无限渲染循环
- `ENSURE_CONTENT_SCRIPT` 被重复调用 30+ 次
- 导致性能问题和功能异常

**根本原因**：
```javascript
// 问题代码
useEffect(() => {
  initializePopup();
}, [initializePopup]); // ← 依赖项导致循环
```

**修复方案**：
- 移除 `useEffect` 依赖项，只在组件挂载时执行
- 移除不必要的 `useCallback` 包装
- 优化组件渲染逻辑

### 页面刷新后无法进入阅读模式

**修复内容**：
- 页面加载时清理注入缓存
- URL 变化时重置状态
- 增强状态同步机制

## 📊 性能改进

| 指标 | 修复前 | 修复后 |
|-----|--------|--------|
| 后台请求数 | 30+ 次/秒 | 1 次 |
| CPU 占用 | 高 | 正常 |
| 内存使用 | 持续增长 | 稳定 |
| 响应速度 | 延迟明显 | 即时响应 |
