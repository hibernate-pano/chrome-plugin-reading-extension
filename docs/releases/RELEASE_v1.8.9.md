## 🐛 Bug 修复

### 修复阅读模式刷新后无法重新进入的问题

**问题描述**：

- 在掘金等网站，进入阅读模式后退出，刷新页面，再次点击进入阅读模式时开关会弹回关闭状态

**修复内容**：

1. **解决单例管理的并发问题**

   - 添加 `isDestroying` 标志防止销毁时的竞争条件
   - 延迟清空 `loadPromise` 避免并发创建多个实例
   - 确保旧实例完全清理后再创建新实例

2. **增强状态一致性**

   - `getStatus()` 方法同时检查内存和 DOM 状态
   - 启用前执行防御性清理
   - 添加最终状态验证

3. **改进错误恢复机制**

   - 所有关键操作都有 try-catch 保护
   - 错误时执行清理操作
   - 返回实际状态而非抛出异常

4. **详细的调试日志**
   - 添加步骤日志帮助问题定位
   - 使用 emoji 提高日志可读性
   - 记录状态变化的每个阶段

## 📝 技术改进

- 优化 `ReadingModeService` 的单例管理逻辑
- 增强 `ReadingModeManager` 的状态检查和清理
- 改进 `toggle()` 方法的错误处理
- 添加防御性编程措施

1. **Chrome 扩展商店**（如已发布）：等待自动更新

   npm install
