# PDF 导出手工验收清单

自动化测试覆盖了纯函数（文档构建、图片懒加载回填、设置校验、文件名清理），
但**以下行为无法在 jsdom 中验证**，必须用真实 Chrome 走一遍。

## 准备

```bash
pnpm run build
```

1. 打开 `chrome://extensions/`
2. 启用**开发者模式**
3. 点击**加载已解压的扩展程序**，选择项目根目录的 `dist/`
4. 确认版本显示 v3.4.0（打印页是 3.4.0 引入的；若已升到 3.5.0，则确认显示 v3.5.0）

## 打印对话框检查（影响逐行一致性）

预览与打印要逐行一致，以下设置缺一不可：

- [ ] 纸张 = **A4**（连物理打印机时尤其注意，打印机默认可能是 Letter/B5，页面矮 18mm 会整体改变分页）
- [ ] 边距 = **默认**（改成「最小/无/自定义」会覆盖 20/18mm 页边距，正文列变宽，换行全部偏移）
- [ ] 缩放 = **100**
- [ ] 对比时浏览器缩放（Ctrl/Cmd +/-）保持 **100%**——缩放只影响预览，不影响打印
- [ ] 背景图形 = 勾选（代码块底色、护眼米色依赖它；样式里已强制 `print-color-adjust: exact`，正常不受此开关影响）

---

## 一、基础流程

- [ ] 点击扩展图标进入阅读模式，工具栏出现**下载图标**（右侧按钮组，夹在历史与设置图标之间）
- [ ] 点击下载图标，**新标签页**打开，标题为「导出 PDF · Folio」
- [ ] 页面显示文章内容，顶部有主题/字号控件和「打印 / 存为 PDF」按钮
- [ ] 工具条在图片加载完成前显示「正在加载图片…」，完成后按钮才可点
- [ ] 点击「打印 / 存为 PDF」→ Chrome 打印对话框弹出
- [ ] 目标选择「**另存为 PDF**」，保存后用阅读器打开

## 二、A4 排版（核心）

- [ ] 打印对话框预览中纸张为 **A4**
- [ ] 页边距为上下 20mm、左右 18mm（预览里正文宽度一致）
- [ ] 正文行宽约 44 个汉字，不越出页面
- [ ] 导出的 PDF 中**文字可选中、可搜索**（这是选择浏览器引擎的核心收益）
- [ ] PDF 体积合理（5 千字文章应在数百 KB 量级，不是十几 MB）
- [ ] 标题不会单独留在页底
- [ ] 段落不会在页尾留孤行

## 三、主题与字号

- [ ] 切到**护眼**主题，页面变米色，导出的 PDF 也是米色
- [ ] 深色主题**没有**出现在打印页（这是刻意的，打印费墨）
- [ ] 字号 +/− 可调，范围 9–13pt，到边界时按钮变灰
- [ ] 「图片」切到**中/小**档，图片明显变小且居中；切回**大**恢复
- [ ] 图片大小档位在导出其他文章时**被记住**
- [ ] 调整字号后切到别的文章再导出，字号设置**被记住**
- [ ] 保存的 PDF 文件名是「标题 - 域名.pdf」

## 四、图片

- [ ] 找一篇**懒加载**的图片文章（Medium、知乎等常见），图片**全部显示**
- [ ] 若有图片加载失败，工具条显示「N 张图片已加载，M 张未能加载（可能是防盗链或已失效）」
- [ ] 用一张明显超时的图片源（如指向不响应的地址）验证：5 秒上限过后工具条
      显示「N 张仍在加载（图片服务器可能无响应）」，而不是一片空白框加沉默
- [ ] 找一篇有**超长竖图**的文章，图片被缩放到一页内，**没有被裁掉**
- [ ] 图片不会因为「还没加载完」而印成空白框

## 五、代码块

- [ ] 找一篇有**短代码块**（< 30 行）的文章，代码块不被分页切断
- [ ] 找一篇有**超长代码块**（> 30 行）的文章，代码块**跨页但不丢内容**
      （这是最容易出 bug 的地方：若代码底部内容消失，说明 break-inside 规则写错了）
- [ ] 代码块**没有**复制按钮和语言标签栏
- [ ] 代码有语法高亮，且颜色在白底/米底上都清晰

## 六、边界情况

- [ ] 标题含 `/ : * ? " < > |` 等字符时，PDF 能正常保存
- [ ] 表格较宽时被压在 174mm 内，**不横向溢出**
- [ ] 连续导出同一篇文章两次，**两次都成功**（token 互不覆盖）
- [ ] 直接在地址栏输入 `chrome-extension://<id>/print.html`（无 token）
      → 显示友好空状态，不是白屏或报错
- [ ] 导出后刷新打印页 → 显示空状态（数据已被清除，不残留）

## 七、内容安全

- [ ] 找一篇正文含 `<script>` 或 `onclick` 的文章
      → 打印页**不执行**任何脚本，工具栏按钮正常
- [ ] 页脚来源链接可点击，且**只显示域名**

## 八、不影响原有功能

- [ ] 工具栏自动隐藏/显示行为正常（导出、阅读历史、设置三个按钮都跟随）
- [ ] 设置面板正常打开关闭，「恢复默认设置」可用
- [ ] 阅读历史面板正常打开关闭，列表可读、单条可删、可清空
- [ ] 导出与阅读面板共存：打开历史面板后点导出按钮，导出仍然可用
- [ ] Esc 退出阅读模式正常（面板打开时先关面板）
- [ ] 切换主题后阅读视图样式正常
- [ ] 代码块复制功能正常
- [ ] 直接打印阅读视图（Ctrl+P）时，工具栏和导出按钮**不出现**在纸面上

---

## 已知限制（不是 bug）

- **不做分页预览**：打印页是连续滚动，不显示分页。精确分页请看 Chrome 打印对话框的预览。
  原因见 `docs/superpowers/specs/2026-09-29-pdf-export-design.md` §6。
- **分页处可能留白**：图片永不跨页切割，放不下的图会整体挪到下一页，原位置留白。图片高度已限 150mm、超半页的代码块/表格允许跨页，留白被约束在可接受范围，但无法消除（除非接受图片被切半）
- **需登录才能看的图片会失败**：图片由浏览器直接加载，扩展不携带目标站点的 Cookie。
  工具条会如实告知「未能加载」与「仍在加载」的数量。
