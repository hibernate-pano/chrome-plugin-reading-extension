# Folio v3.6.0

纯阅读、零干扰——把任意网页变成干净的阅读视图，并导出为 A4 排版的 PDF。
无服务器、无统计、仅 3 个运行时依赖，所有数据只存在你自己的浏览器里。

本版本是一次**发布前加固**：五个方向并行深审，每条发现由第二位工程师独立复核，
确认成立的部分已修复并补上回归测试。

---

## 🔒 安全修复

### 修复一个真实 XSS

`ReaderView` 在把文章节点拼回 HTML 字符串时，直接回吐文本节点的 `nodeValue`
——而 `nodeValue` 是**已解码**的文本。消毒器刚把 `<` 转义成 `&lt;`，解析回
DOM 后又变回真 `<`，再经 `dangerouslySetInnerHTML` 注入，等于把消毒器的
努力原地撤销。

触发条件很平常：一段讲解 HTML 的正文，或者任何**紧挨着代码块**的段落。
结果是那段文字在阅读器里变成活的 DOM 节点。

已在真实 Chrome 中复现并验证修复。

### 懒加载图片绕过 URL 协议检查

`data-src` 这类懒加载属性既不在协议白名单里，也不在剥离名单里，因此完全绕过了
全流程唯一的 URL 校验；而打印页会把 `data-src` 直接提升为活的 `src`。
现在校验逻辑收敛到单一出口，两条路径不会再各写一套而漂移。

> 影响范围限于纵深防御：`img[src]` 是媒体上下文，`javascript:` 与
> `data:text/html` 在其中不会执行。修的是不变量被破坏这件事本身。

## 🐛 缺陷修复

- **并发进入阅读模式会白屏。** 守卫在两个 `await` 之后才置位，两条并发的
  `ENABLE_READING_MODE` 都会通过检查，第二条卸载了第一个的宿主节点却复用
  它的 React root——阅读器永久空白，且两次调用都报告成功。
- **双击工具栏会注入两份脚本。** 同一标签页出现两个常驻消息监听器，
  阅读记录会重复计入。
- **设置保存失败后状态错乱。** 内存、界面、存储三层不一致，下次任意重绘会
  回滚到从未保存过的值。现在失败会回滚并明确报错；且回滚采用比较再赋值，
  不会把并发中已成功的写入一起撤销。
- **阅读历史在并发下互相覆盖。** 同一页面内的读改写已串行化。**读失败不再
  被折叠成空数组后写回**——那会清空全部历史并报告成功。
- **用齿轮按钮关闭面板时不归还焦点**，Tab 会走到宿主页面。

## ♿ 可访问性

- 主题选择器此前声明 `role="radiogroup"` 却是三个 Tab 停靠点、方向键完全无效。
  现改为标准的单一 Tab 停靠点 + 方向键 / Home / End，选择跟随焦点。
- 点击面板内不可聚焦的内容（标题、段落、内边距）会把焦点丢给 `<body>`，
  焦点陷阱两个分支都不匹配，Tab 直接走出模态框。现在会把焦点拉回面板。
- 错误边界的重试回调允许返回 Promise，此前被丢弃，失败会变成未捕获的 rejection。

## 📦 安装

1. 下载 `folio-reader-v3.6.0.zip` 并**解压**
2. 打开 `chrome://extensions/`
3. 右上角开启「开发者模式」
4. 点「加载已解压的扩展程序」，选择解压出来的 **`dist` 文件夹**

> Chrome 不支持直接加载压缩包，必须先解压再选 `dist` 目录。
>
> 浏览器要求：Chrome 102 或更高。

## 🖨 已知限制

这些**不是 bug**，但容易被误判为故障：

- **打印对话框请保持默认**：纸张 A4、边距「默认」、缩放 100%。打印机默认
  可能是 Letter（比 A4 矮 18mm），会整体改变分页。
- **预览页是连续滚动，不提供分页预览。** 浏览器没有分页查询 API，自行模拟的
  断页与实际输出必然有偏差。精确分页请用 Chrome 打印对话框的预览。
- **图片处可能留白**：图放不下当前页时会整体挪到下一页。已通过限制图片高度、
  允许超长代码块跨页把留白收敛，但无法消除（除非允许图片被切半）。
- **需登录才能访问的图片会失败**：扩展不携带目标站点的 Cookie。
- **只提供 `srcset` 的图片会打印为空白**：懒加载回填只读 `data-src` 这类属性。
  `srcset` 在 HTML 消毒阶段就被整体剥离（页面可以用它决定加载哪些像素、
  花多少流量，这不是读者该替页面做的决定）。绝大多数站点同时给 `src`，
  那种情况不受影响。
- **跨标签页的阅读历史仍可能丢记录。** 每个标签页是独立的模块副本，
  跨标签页并发无法用队列串行化。彻底修复需要改存储布局，属于后续版本规划。

## 🔒 权限说明

| 权限                 | 用途                             |
| -------------------- | -------------------------------- |
| `storage`            | 保存主题、字号、阅读历史         |
| `activeTab` / `tabs` | 在当前标签页启用阅读模式         |
| `scripting`          | 按需注入阅读脚本                 |
| `<all_urls>`         | 读取文章正文。经扩展商店审核需要 |

不收集任何数据，无网络请求，无遥测。
