# AI 阅读助手项目概述

## 项目简介

AI 阅读助手是一个小而美的 Chrome 浏览器扩展，旨在提供优质的网页阅读体验。该扩展通过智能排版、样式优化和多种自定义设置，让用户能够专注于内容本身，减少阅读疲劳，提升阅读效率和舒适度。

## 当前功能

### 1. 阅读模式转换

- **内容提取**：使用 Mozilla Readability 库智能提取网页主要内容
- **干扰元素移除**：自动移除广告、导航栏等干扰阅读的元素
- **一键切换**：通过扩展弹窗或快捷键快速进入/退出阅读模式

### 2. 排版优化

- **智能段落处理**：优化段落间距和行间距
- **中英文间距处理**：使用 Pangu.js 自动在中英文之间添加空格，提升可读性
- **首行缩进控制**：可选择是否启用首行缩进
- **文本对齐方式**：支持左对齐、居中和两端对齐

### 3. 样式自定义

- **字体选择**：提供多种字体选项（系统默认、宋体、黑体、楷体、苹方、微软雅黑）
- **背景颜色**：多种预设背景色（纯白、暖色、冷色、复古、奶油、薄荷、灰色）
- **字体大小调整**：可调整正文和代码的字体大小
- **行高和行间距**：精细控制文本的行高和行间距
- **段落间距**：可调整段落之间的间距
- **字间距**：控制字符之间的间距
- **页面宽度**：调整内容区域的宽度

### 4. 代码块优化

- **语法高亮**：支持多种编程语言的代码高亮显示
- **代码主题**：提供多种代码高亮主题（GitHub、One Dark、One Light、Material Dark、Material Light、Night Owl、Dracula、Solarized Dark、Solarized Light）
- **行号显示**：自动为代码块添加行号
- **复制功能**：一键复制代码块内容

### 5. 内容导航

- **自动目录生成**：根据页面标题自动生成目录
- **目录导航**：点击目录项快速跳转到对应位置
- **目录显示控制**：可选择是否显示目录

### 6. 多媒体内容控制

- **图片显示控制**：可选择是否显示图片
- **懒加载优化**：优化图片加载方式，提升性能

### 7. 主题支持

- **明暗主题**：支持明亮和暗黑两种主题模式
- **自动适应**：可根据系统设置自动切换主题

## 技术实现

### 核心技术栈

- **前端框架**：React 18
- **开发语言**：TypeScript
- **构建工具**：Vite
- **状态管理**：Zustand
- **样式方案**：Tailwind CSS
- **代码高亮**：Prism.js
- **内容提取**：Mozilla Readability
- **中英文间距**：Pangu.js

### 架构设计

项目采用模块化设计，主要包含以下模块：

1. **内容脚本（Content Script）**
   - 负责页面内容的处理和优化
   - 实现阅读模式转换
   - 处理段落间距和排版
   - 实现代码块高亮

2. **弹出窗口（Popup）**
   - 提供快捷功能访问
   - 显示当前页面状态
   - 提供设置面板入口

3. **后台脚本（Background Script）**
   - 处理扩展生命周期事件
   - 初始化默认设置
   - 处理跨页面通信

4. **存储模块（Storage）**
   - 管理用户设置和偏好
   - 处理数据持久化
   - 提供数据同步功能

5. **状态管理（Store）**
   - 使用 Zustand 管理全局状态
   - 处理组件间的数据共享
   - 管理用户交互状态
