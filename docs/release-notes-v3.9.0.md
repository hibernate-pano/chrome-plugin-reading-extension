# Folio v3.9.0

纯阅读、零干扰——把任意网页变成干净的阅读视图，并导出为 A4 排版的 PDF。
无服务器、无统计、仅 3 个运行时依赖，所有数据只存在你自己的浏览器里。

本版本的两条主线：**打印前可以手动裁掉不要的尾巴**，以及
**排版密度可以自己调**——同一篇文章，省纸与排版不必再二选一。

---

## ✂️ 打印前手动裁剪

长文章经常是「前面值得读，后面是附录」。这一版把裁剪权交给你：**进入「裁剪」
模式后，点击正文里第一段你不想打印的内容，它之后的一切都不会出现在纸上。**

- 工具条上的「裁剪」按钮进入模式（Esc 退出）；此时可截断的段落会亮起描边，
  鼠标移上去还会浮出「从这里截断（含此段）」的提示
- 每页右上角还有一个「删除本页及之后」——「这一整页往后都不要」不必再逐段找
- 状态条常驻「已裁剪至 N 页 · 「被截掉那一段的摘录」」，并带一个「撤销」按钮；
  页数旁边还会挂一枚「已裁剪」徽章，点它可随时回到裁剪模式
- **裁剪过的导出文件名带「（已裁剪）」后缀**（`某篇文章 - example.com（已裁剪）.pdf`），
  撤销后恢复原名。此前两次导出——一次裁剪、一次没裁剪——会拿到同一个文件名，
  先导出的那份被无声覆盖
- 标题与来源链接留在纸上：裁的是正文，署名不跟着走

裁剪只对**这一次导出**生效。关掉打印页，文章原样还在。

## 📐 排版密度可调

打印用的纸是有限的，密度却是每个读者的口味。工具条上新增两个步进器，
改动即时重新分页，下次打开还在：

- **行高** 1.4 – 1.9（默认 1.6）：行与行之间的距离
- **段距** 0 – 1.25em（默认 0.5em）：段落之间的留白
- 两项偏好都被记住，下次导出直接沿用
- **列表项之间的间距也跟着段距走**：此前是写死的 0.35em，现在按段距的一半算
  （默认 0.5em 段距下即 0.25em）。列表本来就读作一整块，条目之间再留一整段
  的空白，读起来像原文并不存在的断句

## 🐞 修掉的打印缺陷

### 图注与段内文字不再丢

一张图和它周围的一段话同处一个 `<p>` 时，此前只把图抽出来做成图注，
**段落里剩下的文字连同那张图一起消失**——PDF 上的内容比屏幕上少。
现在图片与它共享的那段文字各归其位，图注归图、正文归正文。

### 图片未就绪时不能打印

图片还在加载时按打印，拿到的是一片空白框，而页数是按旧版式算的。
现在打印按钮会等到图片解码完成（或 5 秒上限）才放行，并如实播报
哪几张没加载、哪几张还在加载——空白图不会再悄悄印上纸。

### 窄窗口下正文列不再被压扁

500px 宽的窗口里，测量列此前被视口压到 **96.29mm**——同一篇文章，页数随窗口
宽度而变，预览里的页码根本不能信。现在测量列**恒为 174mm**、纸面**恒为 210mm**，
无论窗口多窄都是同一个版式；窄窗口改为横向滚动，纸面左边也永远滚得到。

### 护眼主题的标题 / 链接 / 代码块配色

护眼主题此前只给纸面上了一层底色，标题、链接与代码块仍用浅色主题的配色，
在米色纸上对比度不对。现在这三种元素各自有护眼主题下的颜色。

> **护眼只作用于纸面**。工具条不是纸的一部分，它仍是浅色，
> 而且打印时本来就会被隐藏。

### 阅读器元信息不重复

byline 里已经写了「12 min read」，阅读器就不再补一个自己的估算——两个读时
放在一起是矛盾，不是信息。现在只有 byline 没写读时的时候才会追加估算。

## 📦 安装

从 Chrome Web Store 安装，或在 `chrome://extensions` 开启开发者模式后
「加载已解压的扩展程序」选择本仓库的 `dist` 目录。

> Chrome 不支持直接加载压缩包，必须先解压再选 `dist` 目录。
>
> 浏览器要求：Chrome 102 或更高。

## 🖨 已知限制

这些**不是 bug**，但容易被误判为故障：

- **裁剪以「块」为单位**：段落、列表、代码块都是整块截断，**不能切在一段中间**。
  图片一般和它的图注写在同一个块里——在图上裁，图注也会跟着裁掉。
- **阅读器的读时去重认得的是几种固定写法**，例如 `12 min read` / `12 min reads` /
  `12 min reading` / `12 分钟阅读` / `12 分钟读完`（`12 minutes read`、
  `12 minute read`、`12min read` 也认得）。但 `12-min read`、
  `12 min. read`、以及光秃秃的 `12 分钟` 认不出来，此时估算仍会被追加，
  可能与 byline 里已有的读时重复。

## 🔒 权限说明

| 权限                 | 用途                             |
| -------------------- | -------------------------------- |
| `storage`            | 保存主题、字号、阅读历史         |
| `activeTab` / `tabs` | 在当前标签页启用阅读模式         |
| `scripting`          | 按需注入阅读脚本                 |
| `<all_urls>`         | 读取文章正文。经扩展商店审核需要 |

不收集任何数据，无网络请求，无遥测。
