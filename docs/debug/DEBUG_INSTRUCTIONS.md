# 📋 调试指南 - v1.8.11

## 🎯 目的

定位并解决页面刷新后无法进入阅读模式的问题。

## 🔧 如何使用 v1.8.11 调试版

### 1. 更新扩展

1. **重新加载扩展**
   - 打开 `chrome://extensions/`
   - 找到 "AI Reading Extension"
   - 点击刷新按钮 🔄
   - 确认版本号为 `1.8.11`

### 2. 打开两个控制台

1. **内容页面控制台**
   - 在任意网页按 F12
   - 切换到 Console 标签

2. **后台服务工作进程控制台**
   - 打开 `chrome://extensions/`
   - 找到 "AI Reading Extension"
   - 点击 "服务工作进程" 或 "背景页"
   - 会打开一个新的开发者工具窗口

### 3. 测试步骤

1. **清理状态**
   ```
   关闭所有标签页
   重新打开一个新标签页
   ```

2. **访问测试页面**
   - 可以使用掘金文章：https://juejin.cn/post/7154286738280546317
   - 或打开本地测试页：DEBUG_TEST.html

3. **执行测试序列**
   ```
   a. 点击扩展图标 → 进入阅读模式
   b. 点击扩展图标 → 退出阅读模式
   c. 刷新页面（F5）
   d. 点击扩展图标 → 尝试进入阅读模式
   ```

### 4. 收集日志

请复制以下两个控制台的完整日志：

#### 内容页面控制台应该显示：
```
📦 [UnifiedContentScript] 内容脚本已加载
   URL: https://juejin.cn/...
   时间: 2024-10-09T...
👂 [UnifiedContentScript] 消息监听器已设置
🏓 [Content] 收到 PING，返回 PONG
```

#### 后台控制台应该显示：
```
📥 [Background] 处理 ENSURE_CONTENT_SCRIPT 请求
📋 [Background] 找到活动标签页: 793109911
🔍 [Background] 检查 tab 793109911 是否已注入...
📡 [Background] 发送 PING 到 tab 793109911...
📨 [Background] PING 响应: {success: true, pong: true}
✅ [Background] Content script 已经存在，无需重新注入
📤 [Background] 返回注入状态: true
```

## 🚨 关键问题识别

### ✅ 正常情况
- 刷新后第一次PING就成功
- 不需要重新注入脚本
- 阅读模式正常切换

### ❌ 异常情况1：脚本未加载
- 没有看到 `📦 [UnifiedContentScript] 内容脚本已加载`
- 可能原因：网页CSP策略阻止

### ❌ 异常情况2：PING失败
- 看到 `📝 [Background] PING 失败`
- 可能原因：消息通道断开

### ❌ 异常情况3：重复注入
- 反复看到 `🔧 [Background] 向标签页注入 content script`
- 可能原因：注入验证失败

## 💡 临时解决方案

如果急需使用，可以尝试：

1. **完全重启Chrome**
   - 关闭所有Chrome窗口
   - 重新打开Chrome

2. **重新安装扩展**
   - 删除扩展
   - 重新添加扩展

3. **使用无痕模式**
   - 在无痕模式下测试
   - 可能避免缓存问题
